Impostazioni ricerca ▸

Usate dalla scansione automatica per orientare la ricerca: nomi di programmi, temi, aree geografiche. Il testo in grigio è quello usato di default se lasci il campo vuoto: inizia a scrivere per sostituirlo con le tue parole chiave.

Svuota tutti i bandi trovati finora. Non tocca parole chiave, frequenza o fonti monitorate.

Una fonte per riga, campi separati da "|": indirizzo della pagina, nome dell'ente/finanziatore (obbligatorio: senza un nome le segnalazioni di quella fonte comparirebbero come "Senza titolo"), categoria ("bandi" oppure "reti"), e un titolo breve facoltativo. Lo scraper controllerà quella pagina e segnalerà quando cambia o contiene le tue parole chiave — puoi incollarne più di una insieme.
